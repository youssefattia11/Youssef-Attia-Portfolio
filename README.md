# Youssef Attia Portfolio

A responsive single-page portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — Midnight Blue + Electric Blue visual design and responsive layout
- `script.js` — mobile navigation, scroll reveal, active navigation, and reading progress

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
2. Replace the `#` social profile links with your real URLs.
3. Replace the photo placeholder with your own photo if you want.
4. Update project placeholders with real work. The displayed projects are illustrative placeholders, not verified client results.

## Cloudflare Pages
For this plain static site, connect the GitHub repository with:
- Framework preset: None
- Build command: leave blank
- Build output directory: `/` (if Cloudflare rejects it, use `.`)
- Root directory: leave blank
