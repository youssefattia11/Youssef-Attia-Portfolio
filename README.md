# Youssef Attia — Personal Portfolio

A responsive multi-page portfolio built with plain HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About, experience, skills, education, and downloadable CV
- `projects.html` — Main projects directory
- `seo-projects.html` — SEO project overview
- `paid-media.html` — Paid media experience
- `contact.html` — Contact details
- `projects/` — Individual SEO project overview pages

## Assets
- `assets/Youssef-Attia-CV.pdf` — CV download linked from the About page.

## Deploy with Cloudflare Pages
- Framework preset: None
- Build command: leave blank
- Build output directory: `/`
- Root directory: leave blank

Upload the complete contents of this folder to the root of the connected GitHub repository. Keep the `assets` and `projects` folders in place so the CV and project pages work.

## Before publishing
- Review all experience dates and descriptions.
- Replace the CV PDF whenever you update your resume.
- Add verified performance data and approved screenshots to case studies before publishing metrics.
